# Sales-Performance-Analysis--Data-Cleaning-PIVOT-Data-Analysis-Data-Visualization-
## I have used Microsoft Excel to:
- Perform basic Data Cleaning on a dirty sales performance dummy dataset sample
- Performed basic PIVOT
 - Created a basic Dashboard and slicers for data analysis

## Analytical questions that can be solved by Dashboard and Slicers:
- Revenue Truth: What is the company's actual revenue after accounting for refunds?
- Underperforming Staff: Which staff has the highest refund-to-sale ratio?
- Time Trend: Are sales increasing or decreasing over the years or month-to-month?
- Best Seller: Which of the company's products are their best sellers and drive a significant percentage of the revenue?
